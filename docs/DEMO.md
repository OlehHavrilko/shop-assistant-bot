# Демонстрация магазина «Полотно»

Это сценарий проверки и записи, а не отчёт о её выполнении. Магазин, товары, цены и остатки вымышленные. Лицензированные фотографии иллюстративные: они не подтверждают точный оттенок и состав ткани. Фактические результаты — в [VERIFICATION.md](VERIFICATION.md).

## Подготовка

1. Запустите один экземпляр с `LLM_ENABLED=false`. Каталог, поиск по словам, уточнения, FAQ и обращения работают без AI-ключа и платных API.
2. Для пустой базы задайте `DEMO_CATALOG_PATH=/app/examples/store_catalog.csv` и `STORE_DATA_PATH=/app/examples/store.json` в Compose: 20 товаров, по пять в категориях «Льон», «Бавовна», «Віскоза», «Муслін». Существующая база автоматически не заменяется; отдельный импорт выполняется после резервного копирования.
3. Менеджер тоже может нажать `/start`, смотреть фото и искать ткань. Его `/help` показывает административные команды. Для проверки обращения и ответа нужен другой Telegram-пользователь; второй клиент дополнительно позволяет проверить независимость заявок. Обращение менеджера самому себе не создаётся.
4. Не снимайте токен, `.env`, личные профили и реальные клиентские сообщения. Не запускайте второй polling с тем же токеном.

## Ручной тест бесплатного режима

Для каждого шага запишите дату, версию, роль и фактический результат. Ожидание в таблице не заменяет проверку настоящего Telegram.

| Шаг | Действие | Ожидаемое наблюдение |
| --- | --- | --- |
| 1 | `/start` | «Полотно», пометка демо, кнопки каталога, поиска, доставки, информации о магазине и менеджера. У менеджера также «Звернення». |
| 2 | «Каталог тканин» → «Льон» | Четыре фотокарточки: SKU, оттенок, состав, ширина, плотность, цена, остаток, дата. «Ще тканини» открывает пятый товар. |
| 3 | `00123` | Siena ivory: 345.50 грн/м, 12.75 м, обновление 2026-10-15 09:00 UTC; фото и предупреждение об иллюстративности. |
| 4 | `123`, затем `COT-010` | Белый Siena отсутствует; остаток синей бавовны уточняет менеджер. Неизвестный остаток не показывается как нулевой. |
| 5 | `льон айворі` | Выбор между `00123` и `LIN-002`; кнопка открывает карточку выбранного SKU. Платный API не нужен. |
| 6 | `хлопок синий` | Варианты из бавовны, включая подходящий по составу муслін; пользователь выбирает сам. |
| 7 | `тканина для сукні` | Подходящие по назначению товары, до десяти вариантов. |
| 8 | `шовк неіснуючий`, затем `NO-SUCH-SKU` | Нет выдуманной карточки; предложение уточнить запрос или открыть каталог. |
| 9 | «Про магазин», «Доставка й оплата» → «Оплата»; `як оплатити?` | Заданные условия вымышленного магазина. Заказы и платежи здесь не принимаются. |
| 10 | Независимый клиент A: «Запитати менеджера» в карточке | Номер обращения клиенту, контекст с артикулом менеджеру. |
| 11 | Менеджер: `/reply НОМЕР Уточню деталі тканини` | Ответ получает клиент A в том же чате. Клиент B со своей заявкой этот ответ не получает. |
| 12 | A пишет ещё раз; управляемый перезапуск и повтор | В HUMAN сообщения идут менеджеру. Режим, номер и каталог сохраняются. |
| 13 | Менеджер: `/bot НОМЕР`; A: `00123` | Поиск у A возобновляется; другая заявка остаётся у менеджера. |
| 14 | Менеджер: `/start`, `льон айворі`, «Написати менеджеру» | Витрина доступна; вместо заявки себе — подсказка команд менеджера. |

Перезапуск: `docker compose restart bot`. `down -v` удалит volume с каталогом и диалогами. Дедупликацию updates и сбои доставки проверяют автоматические тесты; видеозапись их не доказывает. Без независимого пользователя шаги 10–13 остаются непроверенными.

## Видео 60–90 секунд

- 0–10 с: `/start`, название, демонстрационные данные.
- 10–30 с: категория, фото и характеристики, «Ще тканини».
- 30–45 с: `льон айворі`, выбор, цена и остаток.
- 45–60 с: доставка и оплата, пояснение об отсутствии заказов.
- 60–80 с: при наличии другого пользователя — обращение, ответ и возврат боту. Без него эпизод не имитируется, ограничение указывается прямо.
- 80–90 с: вымышленные данные, иллюстративные фото, бесплатный детерминированный поиск, без платежей и резервирования.

Сохраните 3–5 кадров работающего Telegram: меню, категорию, фотокарточку, выбор и проверенный диалог с менеджером. Не рисуйте ответы и не выдавайте тесты за настоящий чат.

## Необязательный эксперимент с LLM

Для демо он не нужен. Anthropic SDK устанавливается через `.[llm]`; запуск требует ключа, тарифов, лимита и разрешения на расходы. Старый набор `evals/cases.json` относится к первоначальным четырём товарам и не оценивает новую витрину. Без реального прогона он не доказывает качество модели.

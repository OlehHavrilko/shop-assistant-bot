# План первого выпуска Shop Assistant Bot

> Внутрішній журнал розробки (мовою оригіналу, російською). Короткий підсумок перевірок для замовника — у [VERIFICATION.md](../VERIFICATION.md).

Задача — законченная бесплатная витрина конкретного вымышленного магазина Shop Assistant, уточнённая 17 октября 2026. Платная модель не является условием выпуска.

## Последовательность и критерии завершения

1. **Каталог и импорт.** SQLite, CSV/XLSX, Decimal, строковый SKU, атомарная замена и закрытые поля. Ошибка сохраняет старые данные; цена и остаток карточки берутся только из БД.
2. **Диалоги и менеджер.** Независимые BOT/HUMAN-диалоги, авторизация по ID, номер заявки, ответ выбранному клиенту и явный возврат боту. Сохранённая очередь, дедупликация update_id, восстановление после перезапуска.
3. **Конкретный магазин.** Shop Assistant, украинский интерфейс, 20 демонстрационных товаров, четыре категории, описание и условия доставки/оплаты. CSV содержит цену, остаток и время; JSON — публичные характеристики. Данные явно вымышленные.
4. **Фотовитрина.** Локальные лицензированные фотографии с источниками; состав, ширина, плотность, назначение. Подписи укладываются в лимиты Telegram, фото обозначены как иллюстративные. Категории, пагинация, главное меню и вопрос о выбранном SKU.
5. **Бесплатный поиск.** Название, оттенок, назначение, явный небольшой словарь UK/RU/EN. Точный SKU приоритетен, несколько совпадений требуют выбора, неизвестный запрос не даёт случайный товар. FAQ без AI. Менеджер смотрит всю витрину со своего аккаунта; заявка себе не создаётся.
6. **Поставка.** Базовая установка и Docker без Anthropic SDK, Compose с volume, bootstrap только явно указанного каталога в пустую базу. CI, тесты, проверка Docker на разрешённом Oracle VPS. Замена старого каталога отдельно после резервной копии с сохранением диалогов.
7. **Приёмка и портфолио.** Сверка документации и кода, полный автоматический прогон, настоящий Telegram: меню, фото, поиск, FAQ. Сквозной сценарий клиент → менеджер → клиент требует другого Telegram-пользователя; два клиента нужны для реальной проверки изоляции. Скриншоты и видео 60–90 секунд только из работающего бота.

## Необязательное расширение

Ранее реализованные Anthropic tool use, бюджет, ограниченный контекст и набор оценки сохраняются отдельно. SDK устанавливается через `.[llm]`. Платная оценка требует ключа, тарифов и разрешения на расходы; её отсутствие не блокирует бесплатное демо. Детерминированный поиск не называется полноценным AI, качество модели не объявляется без измерения.

## Работа и размещение

Каталог и поиск, Telegram-интерфейс и демоданные с медиа собираются по отдельности и проверяются сначала сами, потом вместе.

Владелец разрешил Docker и размещение на Oracle VPS. Локальный Docker не нужен. Адрес, ключи и секреты в репозиторий не копируются. Перед обновлением проверяются работающие сервисы и создаётся копия БД. Long polling не требует внешнего порта.

## Фактическое состояние и оставшиеся проверки

На 18 октября 2026 реализованы и установлены витрина, 20 товаров, бесплатный поиск, фотокарточки, единое меню клиента и менеджера, кабинет обращений, история, архив, нативный Reply и темы переписки. Название — Shop Assistant. Скриншоты и презентация опубликованы в портфолио и сохранены в `docs/portfolio/`; видео необязательно.

Последние результаты проверок и развёртывания — в [docs/VERIFICATION.md](VERIFICATION-LOG.md). Остаются повторный сквозной сценарий клиент → менеджер → клиент после исправления и проверка изоляции двумя независимыми клиентами. Роли ради демонстрации не ослабляются, платная модель не требуется.

# Shop Assistant Bot

Telegram-ассистент для небольшого магазина тканей: поиск товаров в каталоге, ответы о цене и наличии, передача сложных вопросов менеджеру.

**Статус:** подготовка к разработке. Пока в репозитории только описание проекта; работающего бота и демо нет.

## Первый выпуск

- Текстовый поиск по артикулу, названию и оттенку.
- Каталог в SQLite, импорт CSV/XLSX фиксированного формата.
- Один LLM-провайдер для определения намерения и поиска. Цену, остаток и время обновления подставляет сервер из БД.
- Уточнение неоднозначных запросов и передача диалога менеджеру с сохранением состояния.
- Поиск по артикулу без LLM, ограничения запросов и расходов на API.

Планируемый стек: Python, aiogram 3, SQLite, SDK одного LLM-провайдера, pytest, Docker.

## Границы

Фото этикеток и подбор аналогов отложены до следующего выпуска. В первый выпуск не входят платежи, корзина, веб-админка и интеграция с реальной 1С.

Самостоятельный демонстрационный проект. Магазин и данные вымышленные; коммерческий опыт и готовые интеграции не заявляются.

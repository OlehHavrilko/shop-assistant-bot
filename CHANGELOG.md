# Журнал змін

## 1.1.0 — 2026-10-18

Інструменти менеджера й власника.

- Менеджер бачить ім'я та @username клієнта у сповіщеннях, списку й картці звернення.
- Фото, файли, голосові й відео в зверненні пересилаються в обидва боки через `copyMessage`; видалений оригінал не блокує чергу.
- Заявка на покупку з картки товару: метри, телефон, доставка, коментар, орієнтовна сума; заявка прив'язується до звернення.
- Оцінка 1–5 після завершення звернення.
- Шаблони відповідей (`quick_replies` у `store.json`) і надсилання картки товару в звернення (`/card`).
- Нагадування про звернення без відповіді (`SUPPORT_REMINDER_MINUTES`) і автовідповідь поза робочими годинами (`working_hours`).
- Оновлення каталогу файлом через бота: перелік змін, підтвердження, резервна копія бази.
- `/stats`: звернення, перша відповідь, оцінки, заявки, ненайдені запити.
- Схема діалогів v4; міграція з v1–v3 зберігає дані. Нова залежність `tzdata`.

## 1.0.0 — 2026-10-18

Перший завершений випуск для портфоліо.

- Пошук виправляє описки: слово з 4+ літер замінюється на близьке слово каталогу з тією самою першою літерою, лише якщо точних збігів немає.
- CI: `ruff check`, тести з Anthropic SDK і без нього на Python 3.11/3.12.
- Помилки LLM логуються за типом винятку, без тексту запиту.
- README для замовника: задача, можливості, адаптація під магазин; англійська версія.
- Документація українською; внутрішній журнал розробки перенесено в `docs/dev/`.
- Виправлено застарілий шлях `DEMO_CATALOG_PATH` у `DEPLOYMENT.md`.
